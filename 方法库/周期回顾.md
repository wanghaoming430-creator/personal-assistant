# 周期回顾（方法库）

正本。本文件是周期回顾的方法参考。

## 一、三种尺度

| 尺度 | 频率 | 输入 | 产出 |
|---|---|---|---|
| 阶段回顾 | 隔几天 | `日志/即时想法/` | 挑出有价值的，归纳成条目 |
| 月度回顾 | 每月 | 阶段回顾 | 重复主题、行为模式、目标进度 |
| 年度回顾 | 每年 | 月度回顾 | 年度总结、下一年方向 |

## 二、阶段回顾怎么做

1. 列出这段时间所有即时想法的标题和时间。
2. 分三类：值得留、可以放、可以扔。默认偏向「可以放」，不逼自己整理全部。
3. 对「值得留」的做三件事之一：扩写成知识条目、转成项目资料、提成记忆候选。
4. 写一份 `YYYY-MM-DD 阶段回顾.md`，只记结论和去向，不复述原文。

## 三、月度回顾怎么做

1. 读本月全部阶段回顾。
2. 找重复出现的主题。同一个念头出现三次以上，值得单独提出来。
3. 看目标进度：`本周清单` 里本月完成的和一直没动的。
4. 可以提画像或记忆的更新建议，但**不自动改**，写成候选交用户确认。

## 四、年度回顾怎么做

1. 读全年月度回顾。
2. 按六块写：重要事件、主要成果、失败与教训、反复出现的问题、长期变化、下一年方向。
3. 不写流水账，每月最多三行。
4. 用 `模板/年度回顾模板.md`。

## 五、禁区

- 不因为「该写回顾了」就催。回顾是工具，不是考勤。
- 不把没整理的即时想法判为失败。
- 不在回顾里替用户下结论，只摆事实和模式。
