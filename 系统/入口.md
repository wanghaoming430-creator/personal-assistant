## 当前结构状态

- 版本：个人助手 V1.5（2026-11-23 升级）
- 推理方式：云端 Agent 主力；本地 Smart Composer + Jan + Qwen3-8B Q4 仅作应急，999-token 硬上限
- 项目结构：项目首页负责导航和状态；项目定位、项目记忆、项目技能是三项核心资产；项目状态只使用进行中、等待外部、已结项、归档
- 项目分工：策划与资料归档分列，具体项目边界写在各自 `项目定位.md`
- 知识位置：`内容/知识/` 与 `沉淀/概念/`（多篇归纳的分析页）都是正式知识位置
- 记忆触发：由 [[记忆规则]] 统一路由；C 事件在 [[助手纠错档案]]，全局 R 在 [[决策习惯]]，项目专属经验在项目记忆
- 用户信息：摘要优先；P 在画像，M 在长期记忆，E/I/B/F 在记忆，C/R 在纠错档案与决策习惯
- 用户信息采集：按 [[用户信息采集计划]] 渐进补充，每次最多一问
- 检索验收：按 [[系统维护/检索验收规范]] 在规则变更、检索失败或月度抽样时执行
- 周度学习：按 [[系统维护/睡眠学习规范]]，由用户手动启动，不做全库基线扫描
- 规则治理：按 [[系统维护/规则适用范围与升级规范]] 判断全局/项目类型/项目专属
- 决策：进入重要决策流程时才查 [[内容/决策/决策索引|决策索引]]
- 工作台：当前库内未保留 `系统/工作台.md`；如后续恢复，仅供 Obsidian 界面使用，不作为模型上下文
- 旧本地 Agent 配置与平台专属文档：已归档到 `系统维护/归档/`，不参与日常运行
