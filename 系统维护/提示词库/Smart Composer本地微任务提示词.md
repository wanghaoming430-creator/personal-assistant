# Smart Composer 本地微任务提示词

> 用途：Smart Composer 1.2.9 + Jan + Qwen3-8B Q4，在 999-token 硬上限内执行单个微任务。只复制当前任务需要的一段，不加载整套全局提示词。

## 一、极简基础指令（约 70 tokens）

```text
你是知识库微任务助手。只处理这一条指令，只引用我给的资料。
不补充资料外的事实，不修改文件，不提出规则。
输出尽量短。资料不足时只说缺什么。
```

## 二、任务模板

### 1. 单条笔记分类

```text
资料：
{粘贴一段短文本}

从下列类型中选一个：知识 / 项目 / SOP / 剪报 / 即时想法 / 日记。
只输出：类型 + 一句理由（不超过 20 字）。
```

### 2. 属性提取

```text
资料：
{粘贴一段短文本}

只提取这些字段：主题、对象、时间、地点。
没有的写“未提”。不要推断。
```

### 3. 短文本摘要

```text
资料：
{粘贴一段短文本}

用不超过 60 字概括。只写资料里的事实，不加评价。
```

### 4. 标题与标签候选

```text
资料：
{粘贴一段短文本}

给出 3 个标题候选（每个不超过 12 字）和 3 个标签候选。
只输出列表，不解释。
```

### 5. 单段格式整理

```text
资料：
{粘贴一段短文本}

只做格式整理：分行、去重复空格、统一标点。
不改写句子，不增删内容。
```

### 6. 单条记忆事件初步分类

```text
事件：
{粘贴一条事件}

判断它更像：助手错误 C / 个人经验 E / 任务偏差 B / 分歧 F / 项目记忆。
只输出类别 + 一句理由。不要写入文件，不要升级为规则。
```

## 三、使用边界

- 一次只运行一个模板；不同时引用项目定位、项目记忆和多份技能。
- 一次只引用一份短文件或一个必要片段。
- 总上下文目标不超过约 800 tokens；接近 900 tokens 时缩小资料或拆分任务。
- 输出只作为候选，不直接改系统规则、画像、长期记忆、项目记忆或批量文件。
- 断网时使用 Obsidian 原生搜索和显式 `@文件` 引用，不依赖 OpenAI Embedding。
- 复杂任务留给云端主力环境，不把完整任务压缩给本地模型。
