# 云端模型接入说明

## 一、定位

本知识库以云端 Agent 作为主力工作环境。用户在所选平台中直接操作知识库文件；平台负责其自身的文件访问、同步、凭据和工具权限。Obsidian 是文件管理与阅读界面。

本库不要求云端模型接入 Smart Composer，也不规定某个平台、产品或 API。模型无关的能力要求见 [[系统维护/模型适配规范]]；本地应急配置见 [[系统维护/Smart Composer本地配置说明]]。

## 二、接入原则

1. 优先使用支持长上下文、文件阅读和按需检索的云端模型。
2. 本地模型只作断网或节省云端 Token 时的应急，不作为主要推理前提；不安装或配置 Ollama。
3. 不把整个 Vault 自动注入上下文。按 `系统/运行入口.md` 的 L0–L5 分层提供资料。
4. 优先提供 `系统/运行入口.md`、当前任务相关文件和必要的上下文摘要；不要把工作台、模板库、全量日志和全量历史记忆作为默认附件。
5. 模型服务商、对话入口或插件变更，不得改变 Markdown 文件结构与数据归属。

## 三、隐私与数据最小化

- 上传文件或通过连接器读取文件前，确认本次任务需要哪些内容。
- 对身份证件、账号凭证、联系方式、财务隐私等敏感内容先脱敏；不需要的字段不要上传。
- 云端模型可能处理并存储请求内容，具体以所用服务商的当前隐私政策、数据控制选项和组织设置为准。
- 云端模型可读取文件，不代表获得修改画像、长期记忆、系统规则或删除文件的权限。
- 不启用无法说明数据流向的自动同步、远程 MCP 或第三方索引服务。

## 四、推荐上下文包

普通任务：
- `系统/运行入口.md`
- `系统/系统规则.md`
- 当前任务相关的 1–3 份正式文件

涉及个性化建议：
- 上述文件
- `个人/用户上下文摘要.md`
- 必要时补充画像/长期记忆中的原始条目

涉及重要决策：
- `系统/记忆规则.md`
- `内容/决策/决策索引.md`
- 同主题决策记录及当前项目文件

涉及项目任务：
- 该项目 `项目首页.md`
- `项目定位.md`、`项目记忆.md`
- 当前任务需要的一份或少量 `项目技能/` 文件

本地微任务：
- `系统维护/提示词库/Smart Composer本地微任务提示词.md`
- 当前任务需要的一份短资料或一个必要片段
- 不加载完整全局提示词、项目定位、项目记忆和全部技能

涉及纠错：
- `系统/记忆规则.md`
- `系统/决策习惯.md` 中的有效 R 规则
- 仅在需要追溯时补充关联 C 事件

周期回顾：
- `系统/记忆规则.md`
- 指定周期内的日志/项目记录
- 不上传全库

## 五、接入验收

- [ ] 能读取标准 Markdown 与 YAML。
- [ ] 能按用户指定文件回答，不要求全库导入。
- [ ] 能区分建议、候选、已确认事实和最终决定。
- [ ] 能在用户确认后修改指定文件，并展示修改差异。
- [ ] 不会把模型平台记忆当作知识库正式记录。
- [ ] 不会自动读取模板、工作台或全量历史资料。
- [ ] 断开模型服务后，Vault 内文件仍可独立阅读和编辑。
