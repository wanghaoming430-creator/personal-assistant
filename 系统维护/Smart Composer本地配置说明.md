# Smart Composer 本地应急配置说明

> 本文件只管 Obsidian Smart Composer 1.2.9 + Jan + Qwen3-8B Q4 的本地备用配置。云端 Agent 平台不接入 Smart Composer，也不依赖它提供文件访问。

## 一、组件与版本

| 项目 | 当前值 |
|---|---|
| Obsidian 插件 | Smart Composer 1.2.9 |
| 本地模型服务 | Jan |
| 本地模型 | Qwen3-8B Q4 |
| 实际最大上下文 | 999 tokens，按硬上限处理 |
| Jan Local API | `[链接已移除] |
| Vault Search Embedding | OpenAI `text-embedding-3-small`，配置 ID `openai/text-embedding-3-small`，1536 维 |

不使用 Ollama。不把 Jan 的聊天模型与 OpenAI Embedding 混为同一个服务。

## 二、本地模式定位

只处理短小、单步、低风险任务：

- 单条笔记分类
- 简单属性提取
- 短文本摘要
- 标题和标签候选
- 单个段落的格式整理
- 单条记忆事件的初步分类（仅候选，不自行升级规则）

不交给本地模式：

- 全局规则设计与改写
- 跨项目规则泛化
- 多文件知识整合
- C/R 冲突裁定与批量合并
- 全库检索分析
- 每周睡眠学习
- 批量改写、删除和高风险文件操作

## 三、999-token 硬上限

该值按总上下文硬上限处理，不使用模型理论上下文窗口替代。

保守运行目标：单次请求的输入、系统指令、引用材料、对话历史和预留输出空间合计不超过约 800 tokens；接近 900 tokens 时缩短材料或拆成独立任务，不把 999 当作日常目标。

| 内容 | 目标预算 |
|---|---:|
| 极简基础指令 | 约 70 tokens |
| 当前微任务指令 | 约 70 tokens |
| 用户请求 | 约 100 tokens |
| 单段资料 | 约 250 tokens |
| 历史对话 | 0–100 tokens |
| 输入合计 | 尽量控制在 590 tokens 左右 |
| 输出预留 | 约 150 tokens |
| 其他余量 | 保留至 800-token 总目标 |

以上只是初始工程预算；中文 Token 切分会因模型和文本变化，以实际运行统计为准。

操作原则：

1. 每次只做一个微任务。
2. 使用 [[系统维护/提示词库/Smart Composer本地微任务提示词]]，不加载完整全局提示词。
3. 不同时加载项目定位、项目记忆和多份技能。
4. 一次只引用一份短文件或一个必要片段。
5. 尽量新开聊天，避免历史对话持续占用上下文。
6. 输出控制在任务需要的最短范围。
7. 资料不足时指出缺少什么，不自行补全。
8. 产生的规则、记忆或技能更新只作为候选，不能由本地模型自行批准。

## 四、配置步骤

1. 打开 Jan，加载 Qwen3-8B Q4。
2. 在 Jan 中启动 Local API Server，确认 `[链接已移除] 可响应模型列表和聊天请求。
3. 在 Obsidian Smart Composer 中添加 OpenAI Compatible 提供者，地址填 Jan Local API。
4. 模型 ID 使用 Jan 中实际启用模型的 ID，不使用猜测值。
5. 若 Jan 启用 API Key，按 Jan 设置配置；不要把密钥写进 Vault。
6. 新开聊天，减少历史上下文；只引用当前微任务需要的一份短资料。
7. 本地模式不承担正式规则、画像、长期记忆和批量文件修改。

## 五、RAG 与离线边界

当前 Vault Search 使用 OpenAI Embedding，它是独立服务，不是 Jan 的聊天模型。

- 在线使用本地 Chat 时，若调用 Vault Search，仍可能请求 OpenAI Embedding。
- 断网时不能依赖 OpenAI Embedding 完成查询向量生成或新增文件向量化。
- 断网应急采用 Obsidian 原生搜索和 Smart Composer `@文件` / `@文件夹` 显式引用少量资料。
- 为减少全部云端调用时，不使用 Vault Search，直接引用当前任务所需片段。
- 不因本地聊天模型切换而自动更换 Embedding 配置。
- 模板、画像、长期记忆和日志仍按 [[系统维护/权限与隐私规则]] 与 [[系统维护/模板与运行时分离说明]] 排除在自动索引之外。

## 六、验收清单

- [ ] Jan 正在运行且 Qwen3-8B Q4 已加载。
- [ ] Local API Server 可响应模型列表和聊天请求。
- [ ] Smart Composer 可完成短文本问答。
- [ ] 断网后本地聊天仍可运行。
- [ ] 断网时不依赖 OpenAI Vault Search。
- [ ] 单次请求总上下文明显低于 999 tokens。
- [ ] 本地模型只输出候选，不直接改系统规则、画像、长期记忆或批量文件。
- [ ] 若 Jan 当前模型无法稳定完成工具调用，退回“生成候选文本—用户手动应用”。

## 七、不在本文件处理的事项

- 云端 Agent 平台的文件访问、同步、凭据和工具权限。
- 云端模型接入验收，见 [[系统维护/模型适配规范]]。
- 本地模型的训练、微调或模型权重管理。
- 用本地模型替代完整睡眠学习或跨项目规则治理。
