# 数据流转规则

## 零、模板边界

模板只在新建、重构或升级正式文件时提供结构参照，不属于日常业务数据流。正式文件生成后以正式文件为准，不重复读取模板。

## 零之二、沉淀层边界

`沉淀/概念/` 是从多篇剪报、资料或实际经验归纳出的分析页，仍属 `类型: 知识`，不是新的第六分类。

- 单篇原始资料留在 `外部收件箱/`，不直接进沉淀层。
- 沉淀页必须保留来源链接、作者与限定条件；计数、占比要闭合。
- 沉淀页与 `内容/知识/` 使用同一套属性、命名和检索规则，并纳入 `知识索引`。
- 从沉淀页形成的稳定方法，按 [[系统维护/规则适用范围与升级规范]] 判断是否进入 `方法库/` 或项目技能。

## 一、信息主链路

```text
即时想法 / 剪报 / 文献参考 / 项目事实
                 |
                 v
          按任务需要整理
                 |
        +--------+--------+
        |        |        |
        v        v        v
      知识     项目资料   流程/SOP
        |
        v
   阶段/月度/年度回顾
        |
        v
   记忆候选 / 决策复盘
        |
        v
   用户确认后更新画像或长期记忆
```

并非所有信息都必须走完整链路。大多数输入停留在原始收件箱或具体项目中即可。

## 二、记忆与决策事件路由

所有触发条件统一见 [[记忆规则]]。本文件不重复维护第二套分类表。

- 无项目归属的个人经历、觉察、任务偏差、分歧 → `个人/记忆.md`
- 多篇剪报或资料归纳出的分析页 → `沉淀/概念/`，仍按 `类型: 知识` 管理
- 助手错误事件 C → `系统/助手纠错档案.md`；当前有效工作规则 R → `系统/决策习惯.md`
- 项目事实、要求、决策链接、经验、偏差、当前进展 → 该项目 `项目记忆.md`
- 项目内可重复的方法 → 该项目 `项目技能/`；一次性工作不建技能
- 一项重要决策的依据、选择、执行与复盘 → `内容/决策/`
- 经用户确认的稳定事实与偏好 → `个人/个人画像.md`
- 经用户确认的跨场景原则 → `个人/长期记忆.md`
- 高频且已确认的用户信息摘要 → `个人/用户上下文摘要.md`，仅作导航，不取代原始记录

## 二之二、从问题到规则的分流

实际使用出现问题后，按以下路径处理，不先写规则：

```text
问题 + 证据 + 所属任务/项目
        │
        ▼
查已有 C、R、项目记忆、项目技能
        │
        ▼
分析根因
        │
        ▼
判断适用范围（全局 / 项目类型 / 项目专属 / 待验证）
        │
        ├── 全局通用 → 全局 R 或系统规则
        ├── 项目类型通用 → 方法库 / SOP / 共享方法候选
        ├── 项目专属 → 项目记忆 / 项目技能
        └── 待验证 → 保留候选，不升级
```

- 范围判据统一见 [[系统维护/规则适用范围与升级规范]]。
- 项目成功经验可以作为其他项目的候选参考，但不得自动复制为其他项目的有效规则。
- 规则互相冲突时保留双方证据，形成冲突提案，不自动覆盖。

## 二之三、项目资产结构

每个正式项目至少具备三项核心资产：项目定位、项目记忆、项目专属技能。项目首页只负责导航和状态，不替代三项资产。

```text
内容/项目/项目名称/
├── 项目首页.md
├── 项目定位.md
├── 项目记忆.md
├── 项目技能/
│   ├── 技能索引.md
│   └── 按实际场景命名的技能文件.md
├── 资料/
├── 过程记录/
└── 成果/
```

这是逻辑结构；已有项目目录不因套用示例而强制搬迁，先映射并补齐缺项。项目仍只使用全库唯一的 `本周清单.md` 管理跨项目待办。

## 三、信息上推判据

1. 未来三个月是否可能再次使用？
2. 是否有明确来源，能区分事实、个人判断与模型推断？
3. 如果不保存，是否会损失可复用信息？
4. 是否已经在其他文件有唯一主记录？

若无复用价值或已有主记录，不重复沉淀。

## 四、周期回顾

- 阶段回顾：只挑值得保留的条目，不要求全部整理。
- 月度回顾：识别重复主题、目标进度和可能的认知变化；只提出候选，不自动改画像/长期记忆。
- 年度回顾：总结重要事件、成果、失败教训、长期变化和下一年方向。
- 回顾只处理指定周期材料，不扫描全库。

## 五、上下文控制

- 运行入口与记忆触发规则提供路由，不承担存储所有历史信息的职责。
- 用户上下文摘要保持短小；详细信息保留在来源文件。
- 索引负责定位，不等于索引命中后必须读取所有结果。
- 工作台、模板、附件、历史日志默认排除在模型上下文之外。
