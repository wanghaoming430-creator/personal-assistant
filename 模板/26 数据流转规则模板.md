# 数据流转规则

## 目的

规定资料从采集、筛选、整理到长期保存的路径，避免收件箱、知识库、决策记录和记忆互相污染。

## 模板库边界

模板库只在新建、重构或升级正式文件时提供结构参照，不属于业务数据流，不进入日常项目资料检索。正式文件生成后，后续处理以该正式文件为依据；不重复读取模板副本。

## 标准流程

外部来源/即时想法 → 外部收件箱或日志 → 阶段回顾与筛选 → 内容/知识或项目 → 记忆/画像更新提案 → 用户确认后写入

## 决策记录流程

决策问题出现 → 建立一份“人生决策”记录 → 记录事前事实、假设、标准、备选方案和预期 → 形成最终决定 → 实际任务进入“个人/本周清单.md” → 到期或新证据出现时回到原决策记录复盘 → 有实质变化时追加修正历史 → 提炼经验候选。

- 一次决策只保留一份主记录；修正和复盘追加在原文件，不覆盖原始判断。
- 事实、假设、预测和实际结果分开记录，避免事后改写当时的判断依据。
- 复盘分别检查判断过程、执行情况和外部因素，不以结果好坏单独评价决策质量。
- 经验候选进入“经验与觉察记忆”；稳定的个人决策原则只能通过个人画像或长期记忆更新提案，经用户确认后写入。
- 决策记录不是任务清单。所有当前有效待办仍只在“个人/本周清单.md”。

## 纠错与记忆流转

- 用户指出助手错误 → 进入“助手纠错与规则沉淀”的 C 错条流水 → 有充分依据且能写清适用边界时，才提炼为 R 规则。
- 任务复盘发现助手偏差 → 进入“经验与觉察记忆”的 B 偏差档案 → 需要形成助手通用规则时，再关联 C/R 规则记录。
- 同一事件若同时符合 C 与 B，只保留一份完整主记录，另一处仅保留编号引用。
- 双方看法不同但没有对错 → 进入 F 分歧记录；纯偏好不得直接写入个人画像。
- 助手发现自己的输出错误并在交付前修正 → 进入系统更新日志；已经对用户输出的，必须明确说明修正内容。
- 不允许助手根据一次经历、一次决策或一次分歧自动推断用户稳定的决策习惯。

## 数据类型流转表

| 输入类型 | 初始位置 | 处理动作 | 目标位置 | 自动处理边界 |
|---|---|---|---|---|
| 临时念头 | 日志/即时想法 | 原样保存，之后回顾 | 阶段回顾/知识 | 不要求当场分类 |
| 网页文章 | 外部收件箱/剪报 | 摘要、保留来源、核实观点 | 内容/知识或项目参考 | 不把原作者观点当成用户观点 |
| 书籍/电影等对象 | 外部收件箱/文献参考 | 补充对象信息和个人体验 | 文献参考 | 不要求转为知识 |
| 项目输入 | 内容/项目 | 记录目标、范围和决策 | 项目笔记 | 任务仍集中在本周清单 |
| 重大决策 | 人生决策记录 | 事前记录、执行、复盘和追加修正 | 原决策记录 | 不覆盖历史，不代替用户作决定 |
| 经验与偏差 | 回顾/任务复盘 | 提炼经验、记录根因和修正 | 经验与觉察记忆 | 不自动推断个人长期习惯 |
| 可复用理解 | 内容/知识 | 归纳、校验、关联 | 知识笔记 | 可在授权范围内整理 |
| 长期个人信息 | 更新提案 | 提交来源、边界与理由 | 个人画像/长期记忆 | 未确认不得写入 |

## 归档/删除判断

| 条件 | 处理方式 |
|---|---|
| 仅有保存价值，无需提炼 | 留在文献参考或剪报 |
| 有可复用观点，来源可追溯 | 提炼知识笔记，并保留来源 |
| 与现有内容重复 | 补充现有笔记，不创建重复条目 |
| 决策已结束但有复盘价值 | 保留原决策记录，更新状态并链接经验摘要 |
| 无信息价值且无后续用途 | 可提出删除建议，用户确认后处理 |

## 运行时检索边界

- 普通项目运行只读取当前项目所需的正式文件、已批准规则和当前有效任务来源。
- 决策跟进回到对应的正式决策记录；纠错或经验回看正式 `系统/决策习惯.md`、`个人/记忆.md` 中相关条目。
- 不因模板中存在某个字段或流程，就自动建立运行任务、提醒、周期检查或全库扫描。
- 模板库不作为运行时事实源、指令源或记忆源。

## 流转检查

- [ ] 来源已记录
- [ ] 事实与个人观点已区分
- [ ] 目标位置正确
- [ ] 没有生成重复待办
- [ ] 决策原始判断没有被覆盖
- [ ] C 与 B 没有重复保存同一事件全文
- [ ] 涉及画像或长期记忆时已走审批流程
