# 模板排版决策规范

> 本文件只在新建文件、重构结构或升级模板时作为排版参照。它不是日常项目运行规则；项目运行应以已经生成的正式文件为准。

## 核心判断

先判断信息的用途和结构，再选择版式。**表格不是统一格式的标志；正确的版式应减少理解和维护成本。**

## 版式选择矩阵

| 信息结构 | 使用形式 | 适用模块 | 避免 |
|---|---|---|---|
| 同类对象、相同字段、需要横向比较 | 表格 | 项目里程碑、风险、画像事实、决策选项 | 混入长段解释 |
| 独立事实或原则 | 无序列表 | 系统规则、人格原则、知识要点 | 把每条拆成表格行 |
| 需要执行或检查 | 复选框 | 本周清单、验收清单 | 用表格做任务墙 |
| 有严格先后顺序 | 编号步骤 | SOP、操作流程 | 对无顺序的观点强行编号 |
| 解释背景、因果和限制 | 短段落 + 小标题 | 知识、项目背景、决策依据 | 把复杂逻辑塞进单元格 |
| 体验、感受、反思、叙事 | 自由叙述 + 提示问题 | 日记、文献感受、月度/年度回顾 | 强制填固定字段 |
| 单条长期信息 | 记忆卡片 | 长期记忆 | 用大宽表保存整段上下文 |
| 时间变化 | 时间线/分期小节 | 年度回顾、项目历程、决策修正历史 | 用过多表格制造流水账 |
| 简单关系 | 一行箭头 | 数据流转、生命周期 | 为简单流程画复杂图 |
| 决策前后状态与多个选项 | 短比较表 + 解释段落 | 人生决策 | 用打分掩盖证据不足 |
| 单次纠错事件与根因 | 短索引 + 独立记录卡 | 助手纠错 | 用超宽表塞入完整经过 |
| 经历与教训的压缩记录 | 固定单行 + 阶段性叙述 | 经验与觉察记忆 | 把完整决策过程复制进经验库 |

## 表格规则

1. 每行必须是同类记录，每列必须是同一字段。
2. 通常 3—5 列；超过 5 列优先拆成两张表或改为卡片。
3. 单元格只放短值，不放整段说明、长摘录或完整操作步骤。
4. 需要排序、筛选或统计的结构化数据才值得做表。
5. 表格只服务于阅读；不能成为唯一存储结构或依赖某个插件。

## 各模块的版式决策

- **入口：** 链接分组优先，当前状态简短呈现；不做全库信息仪表盘。
- **系统规则：** 短句规则 + 权限矩阵；每条规则必须可执行或可检查。
- **助手人格：** 原则清单 + 行为边界；不做“人格评分表”。
- **个人画像：** 事实可表格化，价值观、目标和偏好用列表/叙述；决策原则仅保留经用户确认的内容。
- **长期记忆：** 短索引 + 独立卡片；避免超宽表和失去上下文。
- **本周清单：** 复选框分区；不做任务数据库，不在项目页重复维护任务。
- **项目：** 目标、范围和进展用叙述；里程碑、资源、风险用表格；决策单独成节。
- **知识：** 结论、解释、原理、应用、限制和来源；不把知识拆成字段仓库。
- **SOP：** 编号步骤为主体；判断分支和异常处理用短表格。
- **文献参考：** 对象事实放属性，个人体验用叙述；访问/阅读记录才适合表格。
- **剪报：** 作者观点与个人理解分开；核实事项用表格；摘录保持必要且简短。
- **即时想法：** 极简元数据 + 自由文本；不添加问题清单，不增加捕捉摩擦。
- **阶段回顾：** 主题归纳 + 内容去向表；决策只列链接和触发原因，详细复盘回到原记录。
- **月度回顾：** 目标进度表 + 反思段落；只列本月需要复盘的决定。
- **年度回顾：** 目标结果表 + 时间线 + 叙事；不将一年压缩成 KPI 表。
- **人生决策：** 事前事实/假设、方案比较、预期和反方审查用短表与段落；结果出现后追加复盘及修正历史。
- **助手纠错：** C 用短索引和事件卡；R 用带边界的规则表；F 单独记录，不与错误混合。
- **经验与觉察记忆：** 萃取库用固定短格式；觉察用阶段叙述；偏差用记录卡；不复制原始决策文件。
- **更新提案：** 原内容/建议内容/来源/反证/审批清单；审批状态必须明确。

## 统一视觉层级

- 一篇笔记一个一级标题。
- 二级标题是主要板块；三级标题用于重复记录或子主题。
- 段落围绕单一主题；优先短段落。
- 重要风险直接写明“禁止、必须确认、停止条件”。
- 不使用非标准 HTML，不依赖表格增强插件存储核心数据。
