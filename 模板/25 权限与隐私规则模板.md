# 权限与隐私规则

## 保护目标

以云端模型为主要推理方式，同时坚持数据最小化、敏感信息脱敏和文件修改审批。知识库数据仍以本地 Markdown 文件为正式来源。

## 数据分类

| 数据类别 | 敏感程度 | 云端模型读取规则 | 写入规则 |
|---|---|---|---|
| 普通知识 | 一般 | 按任务提供必要文件 | 按授权整理 |
| 项目资料 | 一般/视内容而定 | 仅提供当前任务相关部分 | 按授权整理 |
| 外部剪报 | 一般 | 可按任务读取，保留来源 | 可整理，保留来源 |
| 个人画像 | 高 | 先读短摘要；需要时提供相关条目 | 更新前必须确认 |
| 长期记忆 | 高 | 先读短摘要；需要时提供相关条目 | 写入前必须确认 |
| 人生决策记录 | 高 | 仅当前相关任务读取 | 新增/修正保留历史 |
| 助手纠错与经验偏差 | 视内容而定 | 按触发规则检索 | 记录实际事件和来源 |
| 私人日记 | 高 | 仅在当前任务明确需要时提供 | 原始记录不自动改写 |
| 模板库 | 一般 | 默认不读取；仅创建/重构时读取指定模板 | 仅用户明确要求时修改 |
| 凭据/密码/密钥 | 极高 | 不提交给模型 | 不写入 Vault |

## 云端处理要求

- 提交前判断当前任务是否真的需要该文件。
- 对证件号、账号密码、密钥、联系方式等敏感字段先脱敏。
- 服务商的数据保留、训练和处理地区以实际服务设置为准。
- 不自动上传整个 Vault，不自动写入模型平台记忆。
- 无法说明数据流向的第三方插件、远程 MCP 和自动索引默认不启用。

## 权限矩阵

| 操作 | 默认权限 | 额外要求 |
|---|---|---|
| 搜索/读取 Vault | 按任务授权 | 只读取相关正式文件，排除模板和工作台 |
| 创建普通新笔记 | 限定允许 | 不覆盖已有文件 |
| 修改普通知识 | 按任务授权 | 保留来源和变更记录 |
| 新建重要决策记录 | 按任务授权 | 不替用户作决定 |
| 修正决策历史 | 追加 | 不覆盖原判断 |
| 修改个人画像 | 禁止直接写入 | 用户确认更新提案后执行 |
| 修改长期记忆 | 禁止直接写入 | 用户确认更新提案后执行 |
| 修改系统规则/人格 | 禁止直接写入 | 先提差异方案并确认 |
| 删除/批量移动/覆盖 | 禁止 | 每次单独审批 |
| 对外发送 | 禁止 | 用户另行明确授权并逐次确认 |

## 安全检查清单

- [ ] 仅提交当前任务必要内容
- [ ] 敏感字段已脱敏
- [ ] 画像/长期记忆修改前需要确认
- [ ] 系统规则修改前需要确认
- [ ] 删除/覆盖操作需要单独确认
- [ ] 不自动上传整个 Vault
- [ ] 不自动写入模型平台记忆
